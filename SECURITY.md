# Responsible disclosure

Please report suspected vulnerabilities privately before sharing technical details in a public issue or pull request.

Use the repository's Security tab and **Report a vulnerability** when that option is available. If it is unavailable, open an issue requesting a private reporting channel without describing the exploit or including sensitive data. A maintainer can arrange a private conversation.

Include the affected version, a minimal reproduction using synthetic data, the expected behavior and the impact you observed. Do not include credentials, personal records or another organization's files. Do not access or modify systems or data you do not own while investigating.

Maintainers will review the report, discuss reproduction and remediation, and coordinate disclosure with the reporter. This process does not promise a response deadline, compensation, or a particular remediation schedule.
